## 一、真机日常观察重点清单

在接下来的 **1~2 周静默稳定观察期** 中，聚焦以下 3 类高频场景的真实体验：

1. **图片与多媒体流媒体秒开**：
   - **拼多多**：商品列表封面图、商详页轮播大图加载是否秒开无白块（验证 `pddpic.com`）；
   - **美团 / 大众点评**：外卖店铺门头、菜品图片、商家详情是否流畅（验证 `meituan.net` / `sankuai.com`）；
   - **小红书**：笔记瀑布流大图、图文详情轮播大图、短视频封面是否有转圈延迟（验证 `xhscdn.com` / `xhscdn.net`）；
   - **快手**：视频流媒体起播速度、头像与直播间封面（验证 `yximgs.com` / `gifshow.com`）；
   - **App Store**：应用图标、截图与预览视频加载速度（验证 `*.mzstatic.com`）。
2. **金融交易与风控防拦截**：
   - **招商银行 / 掌上生活**：饭票购买、信用卡还款、账户查询是否极速且无异地登录警告（验证 `cmbchina.com` / `cmbimg.com`）；
   - **云闪付**：付款码生成、卡管理、乘车码（验证 `unionpay.com` / `95516.com`）；
   - **支付宝**：账单查询、小程序商户图片加载（验证 `alipayobjects.com`）。
3. **音视频与云存储传输**：
   - **网易云音乐**：无损音频起播缓冲延迟、专辑封面与歌词同步（验证 `music.163.com` / `music.126.net`）；
   - **哔哩哔哩**：动态图片、弹幕服务器与高清视频流（验证 `bilibili.com` / `bilivideo.com` / `hdslb.com`）；
   - **百度网盘**：相册自动备份、大文件下载是否保持国内直连带宽，不消耗代理流量（验证 `baidupcs.com`）。

## 三、真机异常排查三步法 (SOP)

若真机使用过程中发现某应用偶发卡顿或加载失败，请按以下标准化步骤定位：

1. **第 1 步：看规则（DIRECT 还是 PROXY）**：
   - 打开 Loon ->【请求记录】或【规则诊断】；
   - 过滤该 App 的域名，检查命中规则集是预期的 `China-Direct` 还是跌落到了末尾的 `FINAL`；
   - 若跌落至 `FINAL`：记录该域名，先比对 [`docs/app-audit-matrix.md`](app-audit-matrix.md) 评估是否属于出海隔离资产。
2. **第 2 步：看 DNS（国内边缘还是跨洋 Anycast）**：
   - 检查该域名解析出的 IP 地址；
   - 判断该 IP 是国内三大运营商机房，还是美英等境外 CDN 节点；
   - 若解析至境外 IP：说明需要评估在 `plugins/Loon-China-DNS.lpx` 中增加就近国内极速解析。
3. **第 3 步：看业务边界（是否触及红线）**：
   - 确认该卡顿域名是否属于出海孪生产品（如 Temu、Kwai、Keeta 等）；
   - 若为海外业务，属于正常的跨境网络开销，严禁粗暴将其拉入国内直连。
