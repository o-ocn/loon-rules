# 个人中国服务覆盖与准入决策矩阵 (China-Personal Matrix)

> **维护原则**：以个人实际使用覆盖与误伤风险为唯一准绳，严防出海双生产品与海外节点倒灌。
> 
> **状态定义**：
> - **A (Active)**: 已进入生产 `China-Personal` 直连层，低风险评估；
> - **B (Observe)**: Phase 1.5 观察池，待核对规则与服务资料或实际场景验证后决定；
> - **C (Excluded)**: 明确排除，绝不纳入直连白名单，维持现有代理策略。
